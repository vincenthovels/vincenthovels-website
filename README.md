# vincenthovels.com

Website van Vincent Hövels, coach en organisatieontwikkelaar.

Statische HTML, gehost via GitHub Pages. Elke wijziging die naar deze repository wordt gepusht,
staat binnen een minuut online.

- Elke pagina staat in een eigen map als `index.html` (bijv. `over-mij/index.html` → `/over-mij/`).
- Afbeeldingen staan in `img/`.
- Gehost via GitHub Pages; `CNAME` bevat het domein. Oude adressen (/about, /blog) hebben een kleine doorverwijspagina.
