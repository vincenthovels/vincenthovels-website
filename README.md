# vincenthovels.com

Website van Vincent Hövels, coach en organisatieontwikkelaar.

Statische HTML, gehost op Netlify. Elke wijziging die naar deze repository wordt gepusht,
staat binnen een minuut online.

- Elke pagina staat in een eigen map als `index.html` (bijv. `over-mij/index.html` → `/over-mij/`).
- Afbeeldingen staan in `img/`.
- `netlify.toml` bevat doorverwijzingen en instellingen.
